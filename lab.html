Artificial Intelligence Hands On

This is the hands on material of the workshop. You'll run all the labs using Jupyter Notebooks

  1. Warmup
    1. Rekognition
    2. Polly
  2. Product Classification with Amazon Machine Learning
  3. Deep Learning
    1. Image classification (ResNet V2) - Cifar 10
    2. Clustering numbers (MNIST) - K-Means
    3. Transfer Learning using a beer dataset
    4. Now, using the sample code and the sagemaker library, convert the Transfer Learning Notebook into a SageMaker project. You should train and publish the BeerNet model using SageMaker
  4. Integration with chatbot
    1. Create a new Intent for calling Product Classification using AML
    2. Create a new Intent for calling Cifar or your BeerNet using lambda and Sagemaker
